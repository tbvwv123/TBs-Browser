# S9 시안 메모 (K~P)

`design-request-S9.md`에 대한 답이다. 시안 파일은 `K-ExtensionsPanel`, `L-AdBlock`, `M-InstallConfirm`, `N-ScriptSettings`, `O-ScriptStore` (각각 `…Dark.dc.html` 포함)와 `P-InPage.dc.html`이다. 색은 모두 `tokens.css`의 기존 값을 썼고, 아래 "새 값"만 새로 생겼다.

시안은 화면에 띄워 확인하지 않았다. 글자 넘침이나 겹침이 보이면 알려 주면 고친다.

## 정한 것

| 항목 | 결정 | 이유 |
|---|---|---|
| 고정 아이콘이 많을 때 | 4개까지 보이고 5개째부터 확장 버튼이 `+N`으로 바뀜 | 260px 폭에서 32px 버튼이 무리 없이 들어가는 한계 |
| 접힌 사이드바의 고정 아이콘 | 보이지 않음. 확장 버튼 하나만 둠 | 44px 폭에 세로로 쌓으면 탭 자리를 먹음 |
| 항목의 설정·고정·지우기 | 줄을 눌러 펼쳤을 때만 보임. 켜기/끄기만 항상 보임 | 한 줄에 버튼 4개는 246px에서 이름을 가림 |
| "이 탭에서 실행" 버튼, 팝업 열기, 업데이트 | 펼친 줄의 왼쪽 글자 버튼 | 아이콘 버튼과 구분 |
| 크롬 확장 안내 문구 | "크롬 확장" 꼬리표에 마우스를 올리면 툴팁. 설치 확인 창에는 문장으로 항상 보임 | 목록에서는 매 줄 반복하지 않음 |
| 방패 버튼의 막은 개수 | 넣지 않음. 팝업에서 크게 보임 | 숫자가 계속 바뀌면 주소창이 시끄럽고 무채색 배지는 잘 안 읽힘 |
| 내부 페이지·새 탭의 방패 | 숨김 | 끌 대상이 없음 |
| 설치 확인이 뜨는 자리 | 주소창 아래 가운데에 붙는 투명 팝업 창 (북마크 팝업과 같은 방식) | 사이드바 상태와 무관하게 같은 자리. 페이지 안에 그리지 않아 사이트가 흉내 낼 수 없음 |
| 설치 확인 닫기 | 바깥을 눌러도 닫히지 않음. "취소"나 Esc로만 닫음 | 실수로 사라지지 않게 |
| "모든 사이트" 경고 | 색을 뒤집은 면 (`--prompt-primary-bg` 바탕, `--prompt-primary-fg` 글자) + 경고 아이콘 | 무채색 안에서 가장 강한 대비 |
| 업데이트 확인 | 새 권한에만 뒤집은 "새로 추가" 꼬리표, 기존 권한은 `--fg-muted` | 늘어난 것만 읽히게 |
| 찾아보기 배치 | 목록형 | 항목 수십 개 수준, 설명 한 줄이 고르는 기준 |
| 스크립트 설정의 칸 자리 | 줄 오른쪽 정렬. 글자 목록만 구역 전체 폭 | 설정 페이지의 줄과 같은 읽는 순서 |
| 오류·업데이트 표시 | 색 대신 굵은 글자 + 점(업데이트) / 경고 아이콘(오류) | 무채색 유지 |

## 남은 물음

- 광고 차단 팝업의 "23개 막음"은 **이 페이지**에서 막은 요청 수다. 탭을 새로고침하면 0부터 다시 센다고 보고 그렸다.
- 차단 목록의 규칙 수와 시각은 자리 표시용 예시 값이다.
- 설치 확인의 권한 문장은 예시다. `script.json`의 권한 이름마다 한 문장씩 정한 표가 있어야 한다.
