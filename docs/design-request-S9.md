# 시안 요청: 확장 패널, 광고 차단, 설치 확인, 스크립트 설정, 찾아보기

받는 쪽: Fable 5.2 · 보내는 쪽: TB's Browser 개발 (2026-11-11)

TB's Browser에 확장 생태계(사이트 스크립트, 크롬 확장, 내장 광고 차단, 스크립트 저장소)를 더한다. 새로 생기는 화면의 시안을 요청한다. 기존 시안 F~J와 같은 디자인 언어로 이어지게 그려 주면 된다.

## 2. 지켜야 할 것 (기존 시안에서 정해진 것)

- **색**: 모두 무채색이다. 그라디언트는 창 바탕에만 쓰고, 버튼·칸·카드 안쪽은 단색이다. 라이트와 다크 두 벌을 그린다(spec 4.3 표).
- **글꼴과 아이콘**: 글꼴은 Inter와 Noto Sans KR, 기본 13px이다. 아이콘은 선 두께 1.8px의 선 아이콘이다.
- **기존 부품을 다시 쓴다**:

  | 부품 | 값 |
  | --- | --- |
  | 메뉴 팝업 | 폭 200px, 모서리 10px, 항목 32px, 메뉴 그림자 |
  | 아이콘 버튼 | 30×30px, 모서리 8px |
  | 사이드바 맨 아래 줄 버튼 | 32×32px |
  | 접힌 상태 버튼 | 36×34px |
  | 탭 줄 | 34px, 모서리 8px |
  | 내부 페이지 | 최대 폭 760px, 제목 22px, 줄 40px (방문 기록·다운로드·설정 페이지) |

- **페이지 위에 뜨는 것은 별도 창이다**: 사이드바 밖으로 나가는 팝업(메뉴, 목록)은 페이지 위에 뜨는 투명 창으로 그린다. 그림자 여백은 16px이다. 창 밖으로 나가지 않게, 크기는 내용에 맞춰 정해진다고 보고 그린다.
- **사이드바 폭**: 펼침 260px, 접힘 44px. 사이드바 안에서 펼치는 것은 이 폭을 넘지 않는다.
- **글**: 화면의 글은 한국어로 쓴다.

## 3. 그려 줄 화면

시안마다 라이트와 다크를 그린다. 상태가 여럿인 것은 한 시안 안에 나란히 놓아도 된다.

### K. 확장 패널

사이드바 맨 아래 줄의 확장 프로그램 버튼(퍼즐 조각)을 누르면 사이드바 안에서 위로 펼쳐지는 목록이다. 지금은 이름만 있는 간단한 목록이다.

- **한 목록에 두 종류**: 사이트 스크립트와 크롬 확장이 함께 있다. 종류는 작게 구분한다(예: "스크립트" / "크롬 확장" 꼬리표).
- **맨 위 묶음**: 현재 탭에 적용 중인 것을 맨 위에 모은다. 그 아래에 나머지를 둔다.
- **항목 한 줄에 들어가는 것**:
  - 아이콘(16px)과 이름
  - 적용 사이트(작은 보조 글자, 예: "youtube.com", "모든 사이트")
  - 켜고 끄기, 고정(핀)
- **항목에 따라 더 붙는 것**:
  - 설정: 스크립트 설정 화면이나 크롬 확장의 설정 페이지
  - 팝업 열기: 크롬 확장
  - "이 탭에서 실행" 버튼: 예) "PiP로 보기"
  - 업데이트 있음 표시
  - 오류 표시: 스크립트 파일이 깨졌을 때
- **아이콘이 없을 때**: 각자 정한 아이콘(파비콘처럼)이 기본이다. 없을 때만 이름 첫 글자를 작은 둥근 사각형에 넣는다. 지금 고정 아이콘이 이렇게 생겼다. 둘이 함께 있을 때의 모습을 보여 준다.
- **패널 맨 아래**: "찾아보기"(스크립트 저장소), "설치…"(zip·폴더), "폴더 열기", "다시 불러오기".
- **크롬 확장 안내**: 크롬 확장에는 "일부 기능은 동작하지 않을 수 있습니다"를 보여 줄 자리가 필요하다. 툴팁이나 항목 안 보조 글자 중 하나로 한다.
- **고정 아이콘 (맨 아래 줄)**: 확장 버튼 왼쪽에 고정 아이콘이 나란히 놓인 상태를 보여 준다. 실제 아이콘과 첫 글자 아이콘이 섞인 경우다. 너무 많을 때(5개 이상) 어떻게 할지도 정해 준다.
- **접힌 상태 (44px, 시안 H)**: 고정 아이콘은 확장 버튼 안으로 들어간다. 이때 확장 버튼을 누르면 패널이 페이지 위 팝업으로 뜬다. 그 모습을 보여 준다.

### L. 광고 차단 (주소창의 방패 버튼과 팝업)

- **방패 버튼**: 주소창 오른쪽, 별(북마크) 버튼 옆에 둔다. 상태는 셋이다.
  - 켜짐: 이 페이지에서 막은 개수를 작게 함께 보여 줄지 정해 준다
  - 이 사이트에서 끔
  - 내부 페이지·새 탭: 숨김 또는 비활성
- **누르면 뜨는 팝업** (페이지 위 팝업):
  - 이 페이지에서 막은 개수
  - "이 사이트에서 광고 차단" 켜기·끄기
  - 끄면 새로고침이 필요하다는 안내
  - 목록을 마지막으로 갱신한 시각
  - "광고 차단 설정" 링크
- **설정 페이지의 "광고 차단" 구역** (기존 설정 페이지에 더함):
  - 전체 켜기·끄기
  - 차단 목록(EasyList, EasyPrivacy, List-KR): 각각 켜기·끄기, 규칙 수, 갱신 시각
  - "지금 갱신"
  - 끈 사이트 목록과 지우기

### M. 설치·권한 확인

스크립트를 설치하거나, 새 권한이 생긴 업데이트를 받거나, "모든 사이트" 스크립트를 처음 켤 때 묻는 창이다. 크롬 확장 zip을 설치할 때도 쓴다.

- **보여 줄 것**: 아이콘, 이름, 만든 사람, 버전, 한 줄 설명.
- **적용 사이트**: 목록으로 보여 준다. "모든 사이트"는 눈에 띄게 경고한다.
- **권한**: 쉬운 말로 풀어 쓴다. 예:
  - "이 탭을 닫거나 뒤로 가게 할 수 있음"
  - "자기 설정을 저장함"
  - "파일을 다운로드 폴더에 저장함"
- **버튼**: "설치"와 "취소". 업데이트일 때는 늘어난 권한만 강조한다.
- **어디에 띄울지 정해 준다**: 페이지 위 팝업, 페이지 카드 안 대화 상자, 내부 페이지 중 하나.

### N. 스크립트 설정 화면

스크립트가 `script.json`에 적어 둔 설정 칸으로 브라우저가 자동으로 그리는 화면이다. 내부 페이지로 열 생각이다(`tbs://scripts/<id>`). 설정 페이지와 같은 틀이다.

- **칸 종류**: 켜기, 숫자, 글자, 글자 목록(더하기·지우기 가능), 고르기(드롭다운).
- **예시 둘을 그려 준다**:
  1. **마우스 제스처**: 방향(←, →, ↑, ↓, ↓→, ↑↓ 등)마다 동작을 고르는 표. 동작은 뒤로, 앞으로, 새로고침, 탭 닫기, 새 탭, 닫은 탭 되살리기, 없음.
  2. **유튜브 사용자 차단**: 차단한 채널 이름 목록. 지우기, 직접 더하기.
- **페이지 머리**: 스크립트 아이콘, 이름, 버전, 적용 사이트, 켜기·끄기, "스크립트 지우기".

### O. 찾아보기 (스크립트 저장소)

확장 패널의 "찾아보기"로 여는 내부 페이지다(`tbs://scripts`).

- 맨 위에 검색 칸.
- **항목**: 아이콘, 이름, 한 줄 설명, 만든 사람, 적용 사이트, 버전.
- **상태 버튼**: 설치 / 설치됨 / 업데이트.
- **빈 상태와 오류 상태**: 검색 결과 없음, 인터넷 없음.
- 목록형과 카드형 중 어울리는 쪽을 정해 준다.

### P. 페이지 안에 그리는 것 (선택)

사이트 스크립트가 웹 페이지 위에 직접 그리는 것이다. 브라우저 UI가 아니어서 사이트 위에서도 잘 보이는 단순한 모양이면 된다.

- **마우스 제스처 궤적**: 오른쪽 버튼을 누른 채 그리는 선과, 인식된 동작 이름 꼬리표(예: "탭 닫기").
- **PiP 버튼**: 영상 위에 마우스를 올리면 나오는 작은 "PiP" 버튼.

## 4. 결과물 형식

- 기존과 같은 `.dc.html` 형식으로 받는다. 파일 이름은 `K-ExtensionsPanel.dc.html`, `L-AdBlock.dc.html`, `M-InstallConfirm.dc.html`, `N-ScriptSettings.dc.html`, `O-ScriptStore.dc.html`, `P-InPage.dc.html`이다. 다크는 각 파일 안에 함께 넣거나 `…Dark.dc.html`로 따로 만든다.
- 새로 정하는 치수와 색은 시안 안에서 숫자로 읽을 수 있게 해 준다. 개발 쪽에서 `tokens.css`로 옮긴다.
- 정하기 어려운 것이 있으면 시안 옆에 짧게 메모로 남긴다. 메모가 필요할 것 같은 것: 방패 버튼에 숫자를 보일지, 고정 아이콘이 넘칠 때, 설치 확인을 띄울 곳.
