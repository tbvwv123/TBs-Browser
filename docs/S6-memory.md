# 6단계 메모리 측정 (spec 7장)

Nov 10, 2026

## 방법

- 같은 사이트 30개를 TB's Browser와 Edge에서 열고, 연 직후와 30분 뒤에 그 브라우저에 속한 모든 프로세스의 메모리를 더했다.
- 도구: `tools/measure-memory.ps1`
  - **개인 작업 집합**: 작업 관리자의 "메모리" 열과 같은 값
  - **커밋**: 프로세스가 잡고 있는 개인 메모리. 디스크로 밀려난 것도 포함
- TB's Browser: 개발 빌드, 새 프로필, 메모리 정책 기본값(안 본 지 5분 재움 / 30분 버림 / 깨어 있는 탭 최대 12개)
- Edge: 157, 빈 임시 프로필(`--user-data-dir`), 확장 없음, 설정 기본값
- 두 브라우저 모두 창을 건드리지 않고 그대로 두었다.
- 사이트: naver, daum, google, youtube, ko.wikipedia, namu.wiki, github, stackoverflow, reddit, news.ycombinator, bbc, nytimes, theverge, developer.mozilla, rust-lang, docs.rs, crates.io, npmjs, svelte.dev, tauri.app, learn.microsoft, apple, microsoft, amazon, netflix, spotify, chess.com, map.naver, papago.naver, weather.go.kr

## 결과

| 시점 | 브라우저 | 프로세스 | 개인 작업 집합 | 커밋 |
| --- | --- | --- | --- | --- |
| 연 직후 | TB's Browser | 26 | 1,559 MB | 2,495 MB |
| 연 직후 | Edge | 58 | 2,947 MB | 3,739 MB |
| 30분 뒤 | TB's Browser | 12 | 615 MB | 1,107 MB |

## 읽는 법

- **연 직후**: TB's Browser는 "깨어 있는 탭 12개" 규칙 때문에 열자마자 18개 탭의 웹뷰를 닫았다. 그래서 프로세스 수와 메모리가 Edge의 절반쯤이다.
- **30분 뒤의 개인 작업 집합**: 두 브라우저가 비슷하다(615 vs 641 MB). Edge는 안 보는 탭의 메모리를 디스크로 밀어내기 때문이다. 그래서 작업 관리자의 "메모리" 열만 보면 차이가 작아 보인다.
- **30분 뒤의 커밋**: TB's Browser 1,107 MB, Edge 3,698 MB다. Edge는 탭 30개의 프로세스를 모두 살려 둔 채 메모리를 디스크로 옮겼을 뿐이다. TB's Browser는 보는 탭 하나만 남기고 나머지 웹뷰를 닫았다. 다른 프로그램이 메모리를 필요로 할 때 실제로 비켜 줄 수 있는 양은 커밋 차이에 가깝다.
- **대가**: 버린 탭을 다시 누르면 처음부터 불러온다. 입력하던 내용과 스크롤 위치는 사라진다(spec 7장). 재운 탭(5~30분)은 상태가 그대로 돌아온다.
