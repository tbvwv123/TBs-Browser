# 나중에 시안으로 한 번에 만들 것

사용자가 시안을 모아서 한 번에 만들기로 한 것들. 시안이 오기 전까지는 지금 모양대로 둔다.

| 날짜 | 화면 | 지금 모양 | 메모 |
| --- | --- | --- | --- |
| 2026-11-11 | 크롬 확장 팝업 창의 제목 표시줄 (spec 6.6) | Windows 기본 제목 표시줄 (확장 이름, 닫기 버튼) | 브라우저의 다른 화면(시안 F~P)과 모양이 다르다. 창을 옮길 수 있어야 하고, 크기 조절은 필요 없다 |
| 2026-11-11 | 시안 K(확장 패널), M(설치 확인)의 다크 | 기존 다크 토큰을 그대로 적용 | Fable 5.2가 라이트만 보냈다 |
