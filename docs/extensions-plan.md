# 확장 생태계 설계안 (2026-11-11 승인)

2026-11-11. 사용자가 원하는 다섯 기능을 확장으로 만들 수 있는 구조를 정한다. 승인받아 spec 6.1·6.3·6.4·6.6~6.9, 8장, 9장에 옮겼다. 이후의 기준은 spec이다. 승인할 때 정한 것: 범위는 이대로, 아이콘은 각자 지정하고 없으면 첫 글자, 시안은 Fable 5.2에 요청(`docs/design-request-S9.md`), 크롬 확장은 배포하지 않고 사용자가 직접 설치.

| # | 원하는 기능 |
| --- | --- |
| 1 | 어떤 영상이든 PiP(작은 창)로 띄우기 |
| 2 | 웨일식 마우스 제스처 |
| 3 | 광고 차단 |
| 4 | 유튜브 사용자 차단 |
| 5 | 크롬 확장 DCRefresher Reborn |

## 1. 먼저 시험한 것 (개발용 프로필, WebView2 157)

| 시험 | 결과 |
| --- | --- |
| 페이지의 `video.requestPictureInPicture()` | **됨.** 브라우저 PiP 창이 떴다가 닫혔다. Document PiP(`documentPictureInPicture`)도 있다 |
| 크롬 확장 등록 (`AddBrowserExtension`) | **됨.** uBO Lite, DCRefresher Reborn 둘 다 등록됐다 |
| 확장의 서비스 워커(백그라운드) | **됨.** uBO Lite가 시작하면서 한국어 목록(`kor-1`)을 스스로 켰다 |
| 확장 페이지 (`chrome-extension://<id>/dashboard.html`) | **됨.** 탭에서 열리고 `chrome.*` API를 쓴다 |
| 콘텐츠 스크립트 | **됨.** DCRefresher가 디시 목록에 기능을 붙였다(글쓴이 옆 통신사 표시 등, 요소 101개) |
| 확장의 네트워크 차단 (`declarativeNetRequest`) | **안 됨.** API는 있고 규칙 묶음도 켜져 있다고 나오지만, EasyList에 있는 광고 스크립트가 그대로 받아졌다 |
| 확장 아이콘, 팝업, 오른쪽 클릭 메뉴(`contextMenus`) | WebView2가 그리지 않는다 (0단계 13번과 같음). 우리가 대신 그려야 한다 |

여기서 나온 결론은 세 가지다.

- 크롬 확장은 대부분 그대로 돈다. 네트워크 차단, 아이콘, 팝업만 빠진다. DCRefresher(5번)는 이 길로 쓴다.
- 광고 차단(3번)은 확장으로는 안 된다. 브라우저가 직접 해야 한다.
- 탭을 닫거나 바꾸는 일(2번)과 설정 저장(4번)은 지금의 사이트 스크립트로는 못 한다. 사이트 스크립트가 부탁할 수 있는 일을 늘려야 한다.

## 2. 구조: 세 갈래

### 2.1 크롬 확장 (spec 6.6을 보조에서 정식으로)

- **설치**: 압축을 푼 폴더 또는 `.zip`. 확장은 `%LOCALAPPDATA%\TBs Browser\extensions\<id>\`에 복사해 두고 시작할 때마다 등록한다.
- **켜기·끄기·지우기**: WebView2의 `Enable`, `Remove`로 한다.
- **확장 허용**: 모든 웹뷰에서 켠다. 0단계에서 확인했듯이 환경 옵션이 모두 같아야 한다.
- **아이콘과 팝업**: 확장 버튼 목록에 확장 아이콘을 그린다. 누르면 `popup.html`을 팝업 창(지금의 콘텐츠 위 팝업)에 띄운다. 고정하면 사이드바 맨 아래 줄에 아이콘이 생긴다.
- **설정 페이지**: 목록의 "설정"을 누르면 `options.html`을 탭으로 연다.
- **안 되는 것**: 네트워크 차단 규칙, 오른쪽 클릭 메뉴 항목, `chrome.tabs`처럼 브라우저 창을 다루는 API는 동작하지 않거나 확인되지 않았다. 확장 목록에 "일부 기능은 동작하지 않을 수 있음"이라고 알린다.
- **업데이트**: 확장 폴더나 zip을 다시 넣으면 바꾼다. 자동 업데이트는 하지 않는다. 크롬 웹 스토어 설치도 하지 않는다.
- **보안**: 확장은 우리 앱 명령을 부를 수 없다. 지금처럼 콘텐츠 웹뷰와 같은 쪽으로 본다.

### 2.2 사이트 스크립트 v2 (부탁할 수 있는 일 늘리기)

지금의 `script.json` 형식은 그대로 두고 항목만 더한다. 새 권한을 가진 스크립트는 켤 때 권한 목록을 보여 주고 묻는다.

| 권한 / 항목 | 할 수 있는 일 | 쓰는 기능 |
| --- | --- | --- |
| `matches: ["*"]` | 모든 사이트에서 실행 (지금도 형식상 됨. 켤 때 "모든 사이트" 경고) | 1, 2 |
| `tabs` | 새 탭, 탭 닫기, 닫은 탭 되살리기, 위·아래 탭, 뒤로·앞으로, 새로고침. 스크립트가 도는 그 탭 기준 | 2 |
| `storage` | 스크립트별 저장 공간 (`scripts\<id>\storage.json`, 최대 5MB). `tbs.storage.get/set` | 2, 4 |
| `settings` (항목) | `script.json`에 설정 칸을 적어 두면(켜기·숫자·글자·글자 목록) 관리 화면이 설정 화면을 그린다. 값은 `tbs.settings`로 읽는다 | 2, 4 |
| `shortcuts` (항목) | 단축키 등록. 페이지에 포커스가 있어도 동작한다 (호스트의 단축키 처리기가 넘겨줌) | 1 |
| `actions` (항목) | 확장 버튼 목록에 "이 탭에서 실행" 버튼을 만든다 | 1 |

보안 규칙은 지금(6.3)과 같다.

- 페이지도 같은 메시지를 보낼 수 있다고 보고, 모든 메시지를 의심한다.
- 보낸 페이지의 주소가 켜진 스크립트의 `matches`에 맞고 그 권한이 있을 때만 처리한다.
- `tabs`는 그 메시지가 온 탭에만 쓸 수 있다. 다른 탭의 주소나 내용은 읽을 수 없다.

### 2.3 광고 차단 (브라우저에 내장)

- **엔진**: Brave의 `adblock-rust` 크레이트(MPL-2.0)를 쓴다. EasyList, EasyPrivacy, 한국어 목록(List-KR)을 받는다. 목록은 하루에 한 번 갱신한다.
- **네트워크 차단**: 모든 요청에 `WebResourceRequested` 필터를 걸고, 막을 요청에는 빈 응답을 돌려준다.
- **화면 숨기기**: 사이트별 숨김 규칙은 콘텐츠 스크립트로 CSS를 넣는다.
- **사이트별 끄기**: 주소창 별 옆에 방패 버튼을 둔다(새 화면 요소라 시안이 필요하다). 막은 개수를 보여 준다.
- **0단계에서 아는 한계**:
  - 서비스 워커를 거치는 요청은 가로채지 못한다. 유튜브 영상 광고처럼 서비스 워커나 페이지 스크립트로 오는 광고는 화면 숨기기와 스크립트로 처리해야 해서 완전하지 않다.
  - 모든 요청이 호스트를 한 번 거친다. 페이지 로딩이 얼마나 느려지는지 먼저 잰다(10단계 첫 시험).

## 3. 다섯 기능을 어떻게 만드는가

| # | 기능 | 갈래 | 만드는 것 |
| --- | --- | --- | --- |
| 1 | PiP | 사이트 스크립트 (`*`, `shortcuts`, `actions`) | 페이지에서 가장 큰 재생 중 영상을 찾아 `requestPictureInPicture()`. 단축키(예: Alt+P)와 확장 목록 버튼. PiP를 막아 둔 사이트는 막은 속성을 지우고 시도한다 |
| 2 | 마우스 제스처 | 사이트 스크립트 (`*`, `tabs`, `settings`) | 오른쪽 버튼을 누른 채 끌면 페이지 위에 궤적을 그리고, 방향(←, →, ↑↓, ↓→ 등)에 따라 뒤로·앞으로·새로고침·탭 닫기·새 탭·되살리기를 한다. 끌지 않고 떼면 원래 오른쪽 클릭 메뉴. 동작 배치는 설정 화면에서 바꾼다 |
| 3 | 광고 차단 | 브라우저 내장 | 2.3 |
| 4 | 유튜브 사용자 차단 | 사이트 스크립트 (`youtube.com`, `storage`, `settings`) | 댓글·영상 목록·추천에서 차단한 채널을 숨긴다. 채널 이름 옆에 "차단" 버튼을 단다. 차단 목록은 설정 화면에서 고친다 |
| 5 | DCRefresher Reborn | 크롬 확장 | 2.1. 받은 zip을 설치하면 끝. 설정은 확장 목록의 "설정"(옵션 페이지 탭) |

1, 2, 4는 `scripts-examples/`에 예시로 넣어 처음 설치할 때 함께 들어간다(꺼진 상태).

## 4. "생태계": 나누고 받는 곳

- **스크립트 저장소**: 공개 GitHub 저장소 하나(예: `tbvwv123/TBs-Browser-scripts`)에 스크립트 폴더와 목록 파일 `index.json`을 둔다.
- **찾아보기와 설치**: 관리 화면에 "찾아보기"를 두고, `index.json`을 읽어 목록을 보여 준다. 설치를 누르면 그 스크립트의 zip을 받아 `scripts\`에 푼다. 설치 전에 권한과 적용 사이트를 보여 주고 묻는다.
- **업데이트**: 하루에 한 번 `index.json`의 버전과 비교한다. 새 버전이 있으면 목록에 "업데이트" 버튼을 띄운다. 권한이 늘었으면 다시 묻는다.
- **만들기 문서**: `docs/scripts.md`에 `script.json` 항목, `tbs.*` API, 예시 셋(1, 2, 4)을 설명한다.
- **크롬 확장**: 저장소에 올리지 않는다(라이선스와 출처가 제각각이다). 사용자가 받은 zip을 직접 설치한다.

## 5. 단계 (9장에 덧붙임)

| 단계 | 만드는 것 | 사용자가 해 볼 시험 |
| --- | --- | --- |
| 9. 크롬 확장 | 2.1 전체: 설치·켜기·지우기, 아이콘·팝업·설정 페이지 | DCRefresher Reborn zip을 설치해 디시에서 쓴다. 팝업과 설정 페이지가 열린다 |
| 10. 광고 차단 | 2.3. 먼저 속도를 재고, 느리면 방식을 다시 정한다 | 광고 많은 사이트 몇 곳에서 광고가 사라지고, 로딩 시간이 크게 늘지 않는다. 사이트별로 끌 수 있다 |
| 11. 사이트 스크립트 v2 | 2.2의 권한과 설정 화면, 예시 1·2·4 | PiP 단축키, 제스처로 탭 닫기·되살리기, 유튜브 채널 차단이 된다 |
| 12. 스크립트 저장소 | 4장: 찾아보기·설치·업데이트, 만들기 문서 | 저장소에 올린 스크립트를 브라우저에서 찾아 설치하고, 새 버전이 업데이트된다 |

## 6. 정해야 할 것

1. **이 범위로 갈지**: 특히 광고 차단을 브라우저에 내장하는 것(2.3)과 스크립트 저장소(4장)를 넣을지.
2. **단계 순서**: 위 표는 이미 되는 것을 가장 빨리 쓰게 하는 순서다(DCRefresher → 광고 차단 → 스크립트 → 저장소).
3. **시안**: 광고 차단 방패 버튼, 확장 아이콘 목록, 설정 화면, 찾아보기 화면은 시안에 없다. 지금의 메뉴·팝업 모양을 따라 만들고 나중에 비교할지, 시안을 먼저 받을지.
